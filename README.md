❖	LiveHousify (property rental web application)	

Tech Stack: Node.js, Express.js, MongoDB Atlas, EJS, Passport.js, joi, Cloudinary, Mapbox, Bootstrap, Render, Git, GitHub.

Project URL: https://livehousify-project.onrender.com/listings 

Project Description:

•	Developed a full-stack property rental web application using Node.js, Express.js, MongoDB, and EJS following RESTful architecture.

•	Implemented secure user authentication with Passport.js, session management, and complete CRUD operations for property listings.

•	Integrated Cloudinary for image uploads and Mapbox for interactive location mapping.

•	Deployed the application on Render with MongoDB Atlas, Git, and GitHub for version control.

•	Implemented the MVC architecture to improve code organization, readability, and maintainability.
